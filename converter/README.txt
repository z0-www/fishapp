鱼者文游 · 离线对话转换器 V1.2.1（手机端）
==========================================

用途
----
把 Chatbox 等应用导出的对话，转换成本地 .yuzhe 故事归档。
然后在鱼者文游中：设置 → 完整故事备份 → 从 .yuzhe 备份恢复。

重要：不要使用「DeepSeek 对话导入」入口。那个入口用于 DeepSeek
文本/分享链接，不读取 .yuzhe 备份。

全程本地处理：不上传聊天、不需要登录、不需要 API Key、不调用 AI。
首次联网打开后，可断网完成选择文件、转换和保存。

支持
----
- Chatbox JSON（含 sessions/chats 数组，或单个 messages 数组）
- Chatbox Markdown（User:/Assistant:/用户：/助手：等角色标记）
- Chatbox 备份 ZIP、DeepSeek 导出 ZIP（按内容识别，实验性）
- 普通 TXT（带角色标记）

Android 推荐路径
----------------
1. 用 Chrome 打开转换器 HTTPS 地址（Cloudflare Pages 等静态托管）。
2. 第一次打开后等页面顶部显示“离线资源已缓存”。
3. 点“选择原始文件”，从系统文件管理器选择 Chatbox 导出的 JSON/Markdown/ZIP。
4. 预览并勾选会话，点“生成 .yuzhe”。
5. 点“保存 / 分享文件”，保存到手机下载目录。
6. 打开鱼者文游 → 完整故事备份 → 从 .yuzhe 备份恢复。

把网站“添加到主屏幕”后，可像 App 一样打开；断网也可用（缓存未被系统清理时）。

iPhone 推荐路径
---------------
1. Safari 打开转换器 HTTPS 地址（本地“文件”里的 HTML 通常不能直接运行）。
2. 分享 → 添加到主屏幕。
3. 点“选择原始文件”，从“文件”App 选择 Chatbox JSON/Markdown/ZIP。
4. 预览并勾选会话，点“生成 .yuzhe”。
5. 点“保存 / 分享文件” → 分享面板 → 存储到文件。
6. 打开鱼者文游 → 完整故事备份 → 从 .yuzhe 备份恢复。

多会话 ZIP：生成后同样点“保存 / 分享文件”，选择存储到文件；
用“文件”App 解压后，逐个恢复 .yuzhe。

电脑备用
--------
解压 ZIP，双击 index.html（Edge/Chrome）即可离线使用。

离线与存储
----------
- 首次在线打开后，Service Worker 缓存页面与转换代码；断网后仍可选择、
  转换和保存文件。
- 如果浏览器存储被清理，断网可能打不开。请联网重新打开一次，等顶部
  显示“离线资源已缓存”后再断网。
- 导出的 .yuzhe 默认不加密，里面是原始对话文本，请妥善保管。
- 转换器不修改原始文件；未识别格式会报错并保留原文件。
- 图片、附件、工具调用参数不会写入归档，预览会提示。
- 真实的 Chatbox 导出样本仍需最终验收；当前按结构识别，不按扩展名硬猜。
