# 手机端使用教程（Android / iPhone）

本教程对应 **转换器 V1.2.1-mobile**。转换器与鱼者文游客户端相互独立，
不需要更新 APK/IPA，也不需要 API Key。

---

## 0. 先记住正确的导入入口

转换完成后，打开鱼者文游：

> **设置 / 世界菜单 → 完整故事备份 → 从 .yuzhe 备份恢复**

**不要**使用「DeepSeek 对话导入」。那个入口用于 DeepSeek 分享文本或链接，
不读取 `.yuzhe` 文件。用错入口会以为“文件损坏/无法导入”。

---

## 1. Android Chrome

### 1.1 打开转换器

推荐把 `FishTextAdventure-Converter-1.2.1-mobile-cloudflare-pages.zip`
上传到 Cloudflare Pages 等 HTTPS 静态托管，得到类似
`https://your-converter.pages.dev/` 的地址。

1. 用 **Chrome** 打开该地址。
2. 第一次打开会显示“手机端使用说明”，点“我知道了，开始使用”。
3. 等页面顶部显示 **“离线资源已缓存，可以断网转换和保存。”**
   如果显示“浏览器可能在空间不足时清理缓存”，仍可使用；只是长期离线要留意。
4. 可选：Chrome 菜单 → **添加到主屏幕**，以后像 App 一样打开。

### 1.2 选择 Chatbox 文件

1. 先在 Chatbox 中导出 JSON、Markdown 或备份 ZIP，保存到手机“下载”目录。
2. 回到转换器，点 **“点这里从手机选择文件”**。
3. 在系统文件管理器中选择导出的文件。
   - JSON / Markdown：直接选择；
   - ZIP：选择 Chatbox 备份 ZIP；
   - 如果看不到文件，点文件选择器左上角菜单 → “下载”/“最近”，
     或确认文件确实已保存到本机。
4. 页面显示“已识别：… · N 个会话 · M 条消息”。

### 1.3 预览、选择、生成

1. 在第 2 步检查会话标题、消息数、角色和提示。
2. 勾选要转换的会话（默认全选）；多选会生成 ZIP。
3. 点 **“生成 .yuzhe”**。
4. 生成后出现 **“保存 / 分享文件”** 按钮，点它。
5. Chrome 会保存到“下载”目录。通知栏/下载列表应出现 `.yuzhe`
   （多会话时是 `.zip`）。

### 1.4 在鱼者文游恢复

1. 打开鱼者文游。
2. 进入 **完整故事备份** → **从 .yuzhe 备份恢复**。
3. 在系统文件选择器中选择刚保存的 `.yuzhe`。
4. 预览会显示世界名、导入消息数；点“确认恢复”。
5. 世界页出现“导入故事的最后片段”，说明消息已导入。

多会话 ZIP：先在“文件”/下载目录解压，得到多个 `.yuzhe`，逐个恢复。

### 1.5 断网

首次在线打开并显示“离线资源已缓存”后：

1. 开飞行模式或断网；
2. 从主屏幕/Chrome 重新打开转换器；
3. 选择文件 → 生成 → 保存，仍可完成；
4. 转换不需要网络；只有“首次加载资源”和“缓存被清理后重新加载”需要联网。

## 2. iPhone Safari

Safari 通常**不能**直接运行“文件”App 里的本地 HTML，所以必须使用 HTTPS
地址（Cloudflare Pages 等）。这是 iOS 的限制，不是转换器故意需要联网。

### 2.1 打开并添加到主屏幕

1. 用 **Safari** 打开转换器 HTTPS 地址。
2. 点 Safari 底部分享按钮 → **添加到主屏幕** → 添加。
3. 从主屏幕打开“鱼者转换器”。
4. 点新手引导“我知道了，开始使用”。
5. 等顶部显示“离线资源已缓存”。

### 2.2 选择 Chatbox 文件

1. 在 Chatbox 中导出文件，保存到“文件”App（iCloud Drive 或“在我的 iPhone 上”）。
2. 在转换器点 **“点这里从手机选择文件”**。
3. 在 Files 选择器中找到导出的 JSON / Markdown / ZIP。
4. 如果文件是灰的：检查扩展名是否为 `.json` / `.md` / `.markdown` /
   `.txt` / `.zip`；也可以先把文件“存储到文件”再选。

### 2.3 生成与保存到“文件”

1. 勾选会话，点 **“生成 .yuzhe”**。
2. 生成后点 **“保存 / 分享文件”**。
3. 在 iOS 分享面板中选择 **“存储到文件”**。
4. 选择“我的 iPhone”或 iCloud Drive 中的文件夹，点“存储”。
5. 打开鱼者文游 → **完整故事备份** → **从 .yuzhe 备份恢复**，
   从“文件”中选择刚才的 `.yuzhe`。

如果分享面板没有“存储到文件”：向上滑动分享菜单 → “更多” → 打开
“存储到文件”；或先保存到“文件”App 再分享给鱼者。

多会话 ZIP：同样保存到“文件”；在“文件”App 中长按 ZIP → 解压，
再逐个恢复 `.yuzhe`。

### 2.4 断网

首次在线打开并缓存后，添加到主屏幕的转换器可离线打开：

1. 关闭 Wi-Fi/蜂窝网络；
2. 从主屏幕打开转换器；
3. 顶部显示“当前离线”；
4. 选择文件 → 生成 → 保存到“文件”仍可用。

如果显示“当前离线，且没有找到完整缓存”，说明系统清理了缓存：
联网重新打开一次，等“离线资源已缓存”后再断网。

## 3. 常见问题

| 现象 | 处理 |
| --- | --- |
| 文件选择器里看不到 ZIP | 用“浏览/下载/最近”，或确认文件已保存到本机；Safari 对本地文件限制较多，优先用“文件”App |
| 点生成后没有下载 | 生成后必须再点“保存 / 分享文件”；Android 检查下载权限，iPhone 选“存储到文件” |
| 导入时提示格式不对 | 确认在 **完整故事备份 → 从 .yuzhe 备份恢复**，不是「DeepSeek 对话导入」 |
| 离线打不开 | 之前未完成首次缓存，或浏览器清理了存储；联网重开一次，等缓存提示 |
| 预览有“附件未转换” | 图片/附件/工具参数不会写入归档；正文和顺序仍保留 |
| 文件解析失败 | 不会生成半成品；原文件不变。请保留样本，便于修正解析器 |
| 多会话 ZIP 如何用 | 解压后逐个 `.yuzhe` 恢复；不要直接把 ZIP 当 `.yuzhe` 导入 |

## 4. 隐私与限制

- 聊天内容只在手机浏览器内存中处理；没有上传接口、远程解析、广告或统计。
- 不需要登录/API Key/AI 调用。
- 导出的 `.yuzhe` 默认不加密，含原始对话文本；请妥善保管。
- 转换器不修改、不覆盖原始 Chatbox 文件。
- 没有真实 Chatbox 样本时，不能宣称兼容所有 Chatbox 版本；当前按公开结构识别。
- 官方 Android 正式包、签名证书和用户存档未被修改。
