手机端使用说明

三步，把 Chatbox 对话带回鱼者

  1. 选择文件从手机“文件”或下载目录选择 Chatbox 导出的 JSON、Markdown 或 ZIP。
  2. 勾选会话并导出预览后点“生成 .yuzhe”，再点“保存 / 分享文件”；iPhone 选择“存储到文件”。
  3. 在鱼者文游恢复打开鱼者文游 → 完整故事备份 → 从 .yuzhe 备份恢复。
不要选错入口 请勿使用「DeepSeek 对话导入」。那个入口用于 DeepSeek 文本/分享链接，不读取 .yuzhe 备份。
文件只在你的手机浏览器内处理，不会上传聊天内容。

手机端转换规则

  • 保留消息正文、顺序、角色（user / assistant / system / tool）和原始换行、Markdown 文本。
  • Chatbox 对话通常没有鱼者世界设定。转换器只生成最小合法世界，不编造 NPC、地点、规则、记忆或剧情；生成字段会在归档中标记。
  • 图片、附件、工具调用参数不会写入归档；预览会列出数量，不会静默丢失。
  • 不修改原始文件；解析失败时不会生成半成品归档。
  • 导出的 .yuzhe 默认不加密，包含原始对话文本，请像聊天记录一样保管。
  • 所有处理都在手机浏览器内存中完成，没有网络请求、没有账号、没有 API Key、没有统计。
  • 导入入口：鱼者文游 → 完整故事备份 → 从 .yuzhe 备份恢复；不是「DeepSeek 对话导入」。
