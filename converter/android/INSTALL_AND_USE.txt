鱼者文游 · 离线对话转换器 v1.2.1 · Android 安装与使用
=====================================================

安装
----
1. 把 APK 传到 Android 手机（数据线、文件管理器或网盘均可）。
2. 点击 APK；如系统提示，允许“安装未知应用”，仅对当前文件管理器授权。
3. 安装完成后桌面出现“鱼者转换器”。它与原版鱼者文游是两个独立 App。

首次打开
--------
1. 阅读手机端三步说明，点“我知道了，开始使用”。
2. 页面顶部显示“本地文件模式：无需缓存，断网也可以直接转换和保存”。
3. 不需要登录、不需要 API Key、不需要联网。

转换
----
1. 点“点这里从手机选择文件”。
2. 在 Android 系统文件管理器中选择 Chatbox 导出的 JSON / Markdown / ZIP。
3. 勾选要转换的会话（可多选）。
4. 点“生成 .yuzhe”。
5. 点“保存 / 分享文件”。
6. 系统会打开 Android 的“保存到”界面；选择 Downloads 或任意文件夹，确认保存。
   - 这一步是系统文件保存，不是网页假下载；保存完成后会显示“已保存”。
   - 若取消，归档仍在转换器内存中，可以再点一次保存。
7. 多会话会生成 ZIP；ZIP 保存后用文件管理器解压，得到多个 .yuzhe。

导入原版鱼者文游
----------------
1. 点转换器结果区的“打开鱼者文游”（若已安装原版）。
2. 在鱼者文游中进入：
   **完整故事备份 → 从 .yuzhe 备份恢复**
3. 选择刚保存的 .yuzhe；预览消息数，确认恢复。
4. 打开恢复出的世界，检查“导入故事的最后片段”的消息顺序和正文。

重要：不要使用「DeepSeek 对话导入」。那个入口用于 DeepSeek 文本/链接，
不读取 .yuzhe 备份。

卸载/更新
---------
- 转换器与原版包名不同，可同时安装，不会覆盖原版。
- 本 APK 由独立正式签名；以后升级必须继续使用同一签名。
- 签名私钥不随 APK 分发。若丢失签名，已安装用户无法无缝升级，只能换包名重装。

隐私
----
- 无 INTERNET 权限；不调用 AI；不上传聊天内容；无广告/统计。
- 无存储权限；文件选择和保存都由 Android 系统界面完成。
- 导出的 .yuzhe 默认不加密，含原始对话文本，请妥善保管。

限制
----
- 图片、附件、工具调用参数不转换，预览会提示。
- 真实 Chatbox 导出样本尚未验收；解析器按公开结构实现，不宣称兼容所有版本。
- 真实 Android 手机、官方正式签名鱼者文游的完整流程仍需按验收清单执行。
