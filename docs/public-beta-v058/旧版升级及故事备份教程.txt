鱼者文游 · 从旧版保留故事

先备份，再换安装包。没完成备份时，保留旧版。

1. 打开旧版。进入「设置 → 完整故事备份」，或进入该世界后用「更多 → 故事备份 → 完整故事备份」。逐个备份你想保留的世界和需要的分支。
2. 点「选择保存位置」，保存到手机「下载」或「文档」文件夹，也可以另存到电脑。不要只保存到应用私有缓存。可选择密码加密，请单独保管密码。
3. 用手机「文件」确认 .yuzhe 文件存在且大小非零。可在仍保留旧版时，通过「设置 → 导入故事」选中该归档，核对出现正确的世界名称、对话和消息数。请保留原件，不需要为预览确认恢复或删除任何世界。
4. 尝试安装同一发布账号提供的新版。若提示签名不一致或无法覆盖，先确认应用外备份已保存且可以预览。只有确认旧版资料均已备份、愿意清除旧 App 的本机数据后，才卸载旧版再安装新版。
5. 新版里打开「设置 → 导入故事 → 从手机选择文件」，选中 .yuzhe，查看预览后点「确认恢复」。核对最近剧情、人物和分支。暂时保留备份，确认所有世界都恢复后再决定如何整理。
6. API Key 不在故事归档。换签名重新安装后，在 Android 本机重新配置自己的密钥。
