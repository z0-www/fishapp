鱼者文游 · DeepSeek API Key 获取教程

1. 在鱼者打开「设置 → AI 服务设置 → 如何获取 API Key？」。图解里用红圈和箭头标出了官网按钮。
2. 点「打开 DeepSeek 密钥页面」，在系统浏览器核对地址 https://platform.deepseek.com/api_keys 。登录自己的 DeepSeek 开放平台账号。
3. 在「API keys」里点「创建 API key」，名称可填「鱼者文游」。创建后在关闭弹窗前点「复制」。
4. 切回鱼者，在 API Key 输入框点「粘贴」，然后「保存 API Key」并确认。离开页面不会自动读取剪贴板。
5. 使用已开放真实在线功能的构建时，可回 AI 服务设置点「手动测试连接」。先看费用提示，确认后才发请求。保存密钥只表示本机已保存。
6. API Key 不要发给任何人，也不要写进截图、论坛或反馈邮件。需要停用时可在 DeepSeek 官方平台撤销对应 Key，并在鱼者本机删除保存项。

鱼者文游软件本体免费。DeepSeek 连接测试及模型请求可能由 DeepSeek 计费。
