鱼者文游 V0.5.8 · Android 公测安装说明

1. 从 B 站账号 z0-www 的公测说明打开夸克网盘分享页，按提示下载同一批发布的 APK 和 SHA256.txt。如有提取码，以同一条 B 站说明为准。安装前对照 SHA256.txt 核对文件；有条件时也与 B 站发布说明里的校验值比对。在 Windows 中可以用 PowerShell 运行 Get-FileHash -Algorithm SHA256 -LiteralPath "你的 APK 路径"。结果不一致时，先重新从原链接下载。
2. 如果手机已有鱼者文游，请先打开旧版，按同目录《旧版升级及故事备份教程》导出并检查备份。安装遇到签名冲突时，保留旧版，先确认备份。
3. 最低系统为 Android 7.0。下载后在手机「文件」中打开 APK。若系统要求允许当前文件管理器安装未知应用，只为此次安装授予该来源权限。安装后可以关闭该权限。
4. 第一次打开，阅读产品声明后点「进入鱼者」。可先创建、编辑或阅读本地故事。
5. 使用在线剧情前，在「设置 → AI 服务设置 → 配置 API Key」保存自己的 DeepSeek 密钥。点「如何获取 API Key？」可查看 App 内带红圈的图解。
6. 如需检查密钥，可以在同页点「手动测试连接」。连接测试和剧情生成均可能由 DeepSeek 计费，请先查看费用确认。鱼者文游本体免费，无会员、无内购。
7. 在首页输入世界构想并发送，按页面提示进入故事。聊天页右侧小鱼图标打开「大肥鱼消费管家」，可查看官方余额、模型、费用记录和预算。查询失败会显示不可用。每日预算是本机的请求控制，服务商按实际账单计费。
8. 「设置 → 导入故事」可选 TXT、JSON 或官方导出 ZIP，也可粘贴对话正文。仅收到 DeepSeek 分享链接时，优先从官方页面复制实际正文。请在预览核对原文后再继续故事。
9. 「设置 → 完整故事备份」选择世界，保存 .yuzhe 到应用外部文件夹。恢复时在迁移中心选择该文件。备份不含系统存储中的 API Key。
10. 安装及使用问题可在「设置 → 关于鱼者 → 意见反馈」复制邮箱，联系 z0www1234@163.com。请提供手机型号、Android 版本、鱼者文游版本及脱敏错误提示。请勿附上 API Key 或私人聊天内容。隐私及在线数据用途请查看同目录《隐私政策与用户须知》。

公测已知问题

• 更早的 Debug 版可能因签名不同而无法覆盖安装。先导出并验证 .yuzhe 备份，再按《旧版升级及故事备份教程》操作。完整备份不包含 API Key，重新安装后需在本机重新配置。
• 本次公测暂未开放通过 DeepSeek 分享链接读取正文。请粘贴实际聊天正文，或导入 TXT、JSON、官方导出 ZIP。
• 密钥无效、余额不足、网络失败时无法生成新回复。仍可使用本机存档。某次调用没有返回用量时，鱼者会保留用量待确认状态，实际费用可到 DeepSeek 平台查询。
