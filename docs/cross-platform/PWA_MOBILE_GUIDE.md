# 鱼者文游 PWA · Android / iPhone 使用教程

前提：主程序和转换器是**两个不同网址**，由你部署到 Cloudflare Pages。
本教程中的 `play.example.com` 和 `convert.example.com` 只是占位，请替换成实际域名。

## Android Chrome

### 主程序

1. Chrome 打开 `https://play.example.com/`；
2. 第一次在线打开，等首屏和字体加载；
3. 点右上角 `⋮` → **安装应用**（没有此项就选 **添加到主屏幕**）；
4. 从桌面“鱼者文游”图标打开；
5. 设置里填写你自己的 DeepSeek API Key；
6. 创建/进入世界，开始文游。

如果只是想用网页，不安装也可以直接使用；安装后更像 App。

### 主程序数据保留

- 世界、备份和 Key 存在当前浏览器站点数据里；
- **刷新/关闭后重新打开，世界应保留**；
- 清除 Chrome 的“网站数据/存储”会删除世界和 Key；
- 请及时在“完整故事备份”导出 `.yuzhe`，并保存到手机“文件/下载”；
- 卸载 Chrome 或换浏览器不会自动迁移数据。

### 离线

- 首次在线打开后，Service Worker 会缓存壳和字体；
- 断网后从桌面图标打开，可进入已缓存界面；
- 离线时不能调用 DeepSeek 生成新剧情；
- 离线可以查看已有世界/备份，具体以页面提示为准。

### 转换器

1. Chrome 打开 `https://convert.example.com/`；
2. 添加到主屏幕；
3. 选择 Chatbox 导出文件；
4. 生成 `.yuzhe`；
5. 点“保存 / 分享文件” → Android 系统保存界面；
6. 回主程序：**完整故事备份 → 从 .yuzhe 备份恢复**。

不要使用「DeepSeek 对话导入」入口。

## iPhone Safari

### 主程序

1. **Safari** 打开 `https://play.example.com/`（必须是 HTTPS）；
2. 底部/顶部 **分享** → **添加到主屏幕**；
3. 从主屏幕图标打开；
4. 设置里填写自己的 DeepSeek API Key；
5. 导入 `.yuzhe`：
   - 主程序 → 完整故事备份 → 从 .yuzhe 备份恢复；
   - 文件选择器里从“文件”App 选择；
6. 导出 `.yuzhe`：
   - 完整故事备份 → 导出；
   - 分享面板 → **存储到文件**。

### iPhone 数据保留与风险

- Safari/主屏幕 PWA 的站点数据可能因存储压力被系统清理；
- 不要只把世界留在浏览器里；
- 每次重要进展后导出 `.yuzhe` 到“文件”App/iCloud；
- 清除 Safari 网站数据会删除世界、Key 和离线缓存；
- 如果离线打不开，联网重新打开一次，让 Service Worker 重新缓存。

### 转换器

1. Safari 打开 `https://convert.example.com/`；
2. 分享 → 添加到主屏幕；
3. 选择 Chatbox JSON/Markdown/ZIP；
4. 生成 `.yuzhe`；
5. **保存 / 分享文件** → **存储到文件**；
6. 回主程序：完整故事备份 → 从 .yuzhe 备份恢复。

## 启动失败怎么办（2026-11-21 新增）

- 新版本启动超过 8 秒会显示“启动较慢”；25 秒会显示错误面板；
- 数据库失败时主程序会显示“本地故事启动失败”，并明确“存档没有被删除”；
- 先点 **重试初始化**；
- 仍失败点 **打开启动诊断**（或直接访问 `https://你的域名/diagnostics.html`）；
- 诊断页只检查资源、SW、IndexedDB/OPFS，不读取 Key/聊天；
- **不要清除 Safari/Chrome 网站数据**，那会删除世界；
- 如果是旧图标/旧页面：
  - 关闭旧标签页/主屏幕图标，重新打开网址；
  - 新 Service Worker 接管后会自动重载一次；
  - 图标仍为问号时，确认 `/icons/Icon-180.png` 返回 200，再删除旧主屏幕图标并重新添加；
  - 删除主屏幕图标不等于清除 Safari 网站数据，但操作前建议先备份 `.yuzhe`。

## 手机版限制（务必知道）

- iPhone Safari 不支持直接运行“文件”里的本地 HTML；必须用 HTTPS 网址。
- PWA 不是 App Store/APK 安装包，不能获得原生分享扩展；
- iOS 的 Web Share 文件支持从 iOS 15 起较好，旧版可能只能走下载；
- 浏览器清理数据会丢世界，`.yuzhe` 是唯一可靠备份；
- 网页端 API Key 存储弱于原生 Keychain/Keystore，且仅 HTTPS 下使用；
- 不建议在公共手机/公共浏览器中输入长期 Key。
