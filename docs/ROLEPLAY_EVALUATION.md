# NPC 自动测试与评估边界

test/roleplay/core_test.dart 覆盖：不同人物不同响应、不无条件服从、重要承诺、来源标签、私人秘密隔离、不在场/死亡角色、瞬移/物品/身份/时间非法变更、玩家意志、有限发言、空场景往返、状态重载、停止不提交、失败保持原存档、预算确认、过期计划与重复事件、迁移保留导入记录。

test/roleplay/ui_test.dart 真正渲染手机游戏页并输入行动，确认预算前 revision=0，点击确认后 revision=1，显示 NPC 台词且不显示 proposal JSON。截图是 Flutter widget 渲染，不是 Android 真机截图。

场景脚本位于 RoleplayScenarios.script，25 个连续行动，涵盖寒暄、沉默、索要资料、承诺、密室暗号、日常、物品、目标、争议和重访。三场景每场景三 NPC；baseline（基础约束）、card（加角色卡）、core（加决策/记忆）三模式各跑25轮，共225个本地 Mock 回合。

这些运行只证明协议、事务和规则稳定；没有真实 DeepSeek 输出、没有自然语言自然度 A/B 排名、没有“某模式更像真人”的分数。本地规则适配器仍使用角色实例作演示，因此不能用该适配器比较真实模型提示词收益。

人工评分口径：自然度30%、决策25%、人格20%、连续性15%、节奏10%，每维0..5；RoleplayEvaluator 只汇总已提供的评分，不自动编造分数。严重错误独立计数，和平均分分开；当前共享 Validator 仅给出 state_or_agency_violation，细分分类与语义评审待扩展。

真实评测后续：在取得适用许可的独立开发环境，用同模型、参数、25轮输入与相同角色初态分别收集三个模式输出；保留原始输出、usage、人工评分与严重错误，评审不知道实验组。重试另计成本。当前任何 Mock 通过率不得作为真实模型表现或双端真机验证。
