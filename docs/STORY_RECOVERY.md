# 旧故事恢复与原味保留

复用 WorldExtractionPipeline、WorldDraft、WorldRecoveryService 与 RecoveryCoordinator，增加 ConversationToWorldEngine 和 StyleDNAExtractor。

## 可实际使用的闭环

文件/文本或获准的公开快照 → 只读历史 → 选择当前分支节点 → 本地标签候选或经费用确认的 AI 整理 → 逐项核实出处、事实性质与知情范围 → “从这里继续” → 独立世界 → Light 对话页。

没有 API Key 也可以保存历史、手工核实与恢复。Mock 整理仅识别明确标签，结果标为候选，不冒充理解完整故事的 AI。真实整理适配器与原生许可共用限制，不能默认调用。

## 来源与冲突

重要项记录 sourceMessageIds、confidence、kind（fact / utterance / inference / rumor / unconfirmed / conflict）、visibility、owners 与 accepted。推测、传闻、未确认、冲突不能直接恢复为确定事实。时间、地点、身份、场景多项冲突不会最后一条覆盖。秘密不自动公开，用户须核实知情人物。

可恢复背景、规则、玩家身份、人物档案、关系、事件、物品、伏笔、当前时间地点及场景；丰富性取决于原始资料与用户审核。不能声称任意数百轮故事一键完整恢复，或自动辨明所有谎言。缺失继续保持未知。

选定节点对应的原文和分支保留。新世界记录来源节点，继承用户已确认的当前场景，而非强制从第一章重来；NPC 上下文使用已审核知情资料，不能把全部旧对话广播给每个人。原有本机故事也能归档成对话，再创建世界副本；已有 checkpoint 分支与节点恢复保留。

## StyleDNA

本地统计选定分支的段落长度、对白行比例和节奏建议，记录来源 ID、算法版本及零 API 请求。只在用户确认后采用短/长段落节奏，不自动复制私密台词到全局 prompt。人物语言样例、目标、情感和共同经历仍应通过有出处的档案审核填写。此版本不具备语义级风格复刻，不宣称复现旧 DeepSeek 模型。

## 数据保护与验证

恢复使用事务创建独立定义、场景存档、分支与检查点。schema 继续为 6，本轮没有删除表、清空或重写旧存档。世界定义版本与已发生剧情分离。

新增实际自动化：110 轮 / 220 条主分支消息及另一分支，原文保留、候选未确认、选定末尾恢复、当前场景和玩家身份进入上下文、失败恢复事务不生成残缺世界。原有迁移、恢复、秘密边界和文件重开测试一并回归。真实模型整理质量仍未测试。
