# 鱼者文游 V0.5.0 · 完整故事备份与导入

## 已实现

- 游戏右上角「世界备份」提供「完整故事备份」和「仅导出世界设定」。迁移中心选择 `.yuzhe` 后预览世界、消息、分支、记忆及缺失附件，再确认恢复。
- V1 归档面向 Android 和 iOS 使用相同 Dart 格式，存储关联世界的设定历史、角色与秘密、地点与规则、历史回合、已导入消息和来源、记忆与摘要、事件、检查点和分支。
- 一致性快照经 SQLite 事务读取。恢复用新 ID 重建世界、检查点、源会话及记忆引用，按归档指纹阻止重复恢复，数据库错误与完整性失败均回滚。
- 归档按记录读取，带 SHA-256 完整性校验。可用 PBKDF2-HMAC-SHA256 600,000 轮和逐记录 AES-256-GCM 加密，密码只用于当前操作。V1 归档带专有魔数、版本和加密标志，未知版本明确报错。SQLite 数据库无需迁移。
- 归档对单文件 64 MiB、单记录 8 MiB、单附件 16 MiB 作限制，可读附件分块复制。无法读取的附件保留元数据，并在保存或恢复前提示。官方导出 ZIP 的整个原包留在源设备，归档打包相关原文、元数据和可读取的独立附件。
- 归档的数据表和字段由白名单限定，安全存储、设备偏好和本机计费记录不在归档范围。已知凭据字段从导入原始元数据移除，可识别凭据文本会阻止归档。自由文本和附件仍由用户审阅。无密码归档可被任何获得文件的人读取。

## 故事导入与隐私

- 官方 ZIP、JSON、TXT 和粘贴内容继续通过同一预览链路。ZIP 仍只识别已验证的导出格式 V3，使用文件流读取，限制路径、目录项、文件数量、单件大小、总大小和解压比例，并核对 CRC。
- DeepSeek JSON 兼容数字和数字字符串的 `id`、`message_id`、`parent_id`。推理、工具和错误角色的片段保留原始元数据。链接缺失正文时无法确认为故事。
- 恢复后，旁白检索自己的记忆和摘要。用户选择的历史摘录和旧版公开消息按受众知情范围筛选，有受限出处的原文不会带给其他角色。
- 匿名分享接口当前保留授权开关。本轮未取得接口公开使用确认或网络正文证据，默认仍可用官方页面复制正文及文件导入。

## 仅通过自动化测试

本阶段全量 275 项通过并构建 Android Debug。随后故事导入及安全专项 55 项通过。专项在全新 SQLite 数据库核对 2 名 NPC、两个分支、8 个剧情回合、3 条导入原文、附件字节、关系、剧情状态和摘要引用。覆盖重复导入、加密恢复、错误密码及预览后损坏文件的回滚。

## 尚未验证

Android 与 iPhone 的实际 Files / 文件选择器往返、两端互恢复、低内存设备的大文件体验、系统进程强制终止后的暂存清理仍待真机验证。官方分享接口与其他导出版本按有合法样本或授权后的实测结果记录。
