# V0.4.5+12 导入验收

本地正文粘贴、TXT、JSON、Markdown 和 DeepSeek 官方 ZIP 继续使用已有导入、预览与恢复流程。用户可以离线审阅原文和来源、选择恢复节点、人工整理人物与剧情并恢复世界。AI 整理须满足直连条件并先确认费用。

只收到分享 URL 时保留待处理入口，显示尚未读取正文，不能保存为聊天或恢复世界。解析成功也至少需要一条可读正文。推理、搜索、附件片段保存在原始数据中，剧情只展示正文。支持 `message_id` 和 `id`，发现双字段冲突会拒绝。公开分享允许缺失分支父节点作为快照边界并提醒，保留原文和现有父节点关系。既有无正文档案仍可查看链接或附件，不能直接恢复剧情。

自动化覆盖多条消息、分支、重复 ID、无正文、不同消息 ID 字段、错误与拒绝重定向。结果来自测试夹具，尚未实际读取任何有效公开链接的多轮消息。上一轮使用无效 ID 的匿名探测得到 HTTP 200 和「分享不存在」。本轮未发出公开分享读取请求。接口使用许可未确认，读取入口受限，当前也没有提供有效验收链接。
