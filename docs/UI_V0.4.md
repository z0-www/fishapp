# V0.4 极简 UI 与截图验收

本轮以 UI/UX 和既有功能适配为范围。现有世界、原始导入、人物、规则、记忆、上下文预算、事务与 API 安全门均保留，没有新增活世界或后台多 Agent。

## 界面

- 主页：菜单 / 鱼者文游 / 更多。中央简短欢迎语，已有世界时仅增加一个继续入口；底部宽圆角输入框，左下加号、右下发送。没有多卡片首页或底部导航栏。
- 创建：自然语言输入 → 本地轻量确认。名称可留空，也可继续详细自定义。保存不调用 AI。首次使用不自动插入示例，已有世界不删除。
- 世界管理：左侧菜单提供新建、最近世界、全部世界、导入和设置；全部世界可搜索。最近列表延续按创建时间排序。
- 聊天：玩家低对比度灰气泡；NPC 名称与台词自然排版；场景使用16sp小说段落、舒适行距。正文不逐段放卡片，费用不常驻主界面。
- 输入：固定底部，遵循键盘安全区；世界输入与聊天草稿本地保存。聊天历史使用惰性列表，辅助历史页每次读取50回合。
- 操作：发送/停止直接可见；加号提供交谈对象、继续故事、重新生成和阅读历史。重新生成使用既有检查点创建独立分支，再确认预算，不覆盖原回复。
- 更多：世界设定、当前人物、地点、剧情时间线、记忆、节点恢复、备份说明等。完整剧情备份文件尚未开放，入口明确说明当前只能导出设定。
- 导入：固定突出“创建世界”“仅保存历史”；详细识别、附件及关联已有世界在展开区域。仅分享链接不会被当作完整聊天。独立系统分享页有返回主页入口。
- 设置：AI 服务、用量与预算、隐私、本地存储和版本等普通列表，不做控制台。

## 视觉与参考

使用用户指定颜色：#FFFFFF、#F6F7F9、#202124、#858A93、#3176C6。统一圆角、系统字体及中文回退，按钮具备至少48逻辑像素交互尺寸，支持系统字号。图标来自 Flutter Material 图标，没有复制 DeepSeek 品牌标志或专有素材。
