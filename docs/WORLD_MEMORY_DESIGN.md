# 世界、记忆与存档

schema 4 只新增 roleplay_saves / roleplay_turns / roleplay_memories。旧 worlds、usage_records、导入队列/原始会话/附件/提取表不删除不重建。按 worldId 隔离，状态保存完整 JSON 与递增 revision，正式回合有唯一 ID、基准版本、行动、所选角色、上下文、响应和状态。记忆还按 owner 隔离。

三层：短期是原始已完成回合；长期稳定事实来自本地状态和角色档案；个人经历为本人听到的玩家言行，带 source（亲历/听说/推断/未确认）、重要度、发生轮数和最后引用轮数。自动写入仅为“玩家说了什么”的亲历记录，不把玩家自述升级为客观事实。外部传闻来源标签可保存/检索，但本轮不自动创建虚假传闻或反思。

检索：先世界后人物，再关键词相关度、重要性、近期性及近期重复引用惩罚，取最多六条；请求最多三轮该人物历史，输入 UTF-8 字节保守估算限制 12000，输出上限 1200。未用云向量库。当前会读取本世界记忆后做本地排序，大量长期记录仍需后续分页索引优化。

WorldState 有时间、当前/玩家地点、在场人物、地点邻接图、已知物品、重要事件与剧情线程。人物身份、位置和存活状态在本地档案中。模型只可提 minutes(0..5)、至多两个有原因的相邻 NPC 移动、玩家明确确认的相邻地点变化；其他身份/生死/物品变更一律拒绝。含糊 events 不提升为事实。重要事件/剧情线程当前是预留集合；正式历史以已完成回合为准。

身份、物品取得和死亡等复杂规则尚未开放，所以不会靠模型一句话就获得宝剑或复活角色。该保守限制也意味着 V0.2 暂不能完成复杂物品任务。自然语言控制玩家的部分高风险句式和跨角色秘密原文被检测，但这不是完整语义证明；隐含的身份/事实漂移必须通过真实模型回归与人工评分进一步评估。

状态与正式回合、个人记忆同事务写入。停止/网络失败/非法 JSON/非法提案/版本冲突不写正式状态；failed/interrupted 账本保留，不自动重试。真实 usage 若已收到，在状态验证前单独记录，因为被拒绝的请求仍可能收费；若中途失败/取消且服务未返回 usage，无法声称零消耗。存档重开、重复确认、schema 3 升级保留旧世界和导入内容都有测试。
