# 上下文、检索与成本

正常行动最多一次模型请求。无后台摘要、隐式重试、付费向量库或常驻多 Agent。

## 七层上下文

L0 明确世界规则与玩家身份；L1 当前场景；L2 当前人物人格、本人私密知识与立场；L3 关系及可知重要记忆；L4 已确认的增量长期索引；L5 最近最多三轮原始消息；L6 当前玩家行动。底层指令先于剧情数据。资料超出预算会报错，不静默删除身份或硬事实。

原始聊天、消息树及历史无损留在 SQLite / 原始档案。IncrementalSummarizer 沿用有出处的本地摘录索引，增量追加、保留原句；这不是语义摘要，索引有时比原元数据更大。用户可预览差异并确认提交，保留旧版本。

MemoryEngine / ContextCompressor 增加本地中文字组、英文词与小型同义词扩展，综合重要度、相关度和时间排序；只读取当前 owner 可知内容。它不是向量语义检索，未覆盖的表达仍可能漏召回。可从原文和时间线工具人工检索。秘密与其他世界不会混入。

## 用量与估价

- 请求前 UTF-8 字节加开销的保守输入估算，明确不是模型 tokenizer。
- 模型返回的实际输入、输出、缓存命中；缺少字段保持未知。
- 请求级保存估算输入、历史字节参考、实际 usage、模型、时间与价格版本，不额外保存密钥或聊天副本。
- 价格集中在 DeepSeekPrices；2026-11-17 峰值快照，不保证实际时段/后续价格。未知模型不估价。
- 费用页展示单次估价、可估价记录总计、未知条目与上下文差异。`actualBilledUsd` 保持 null：API 未返回实际货币扣款，不能伪造账单。
- 停止、网络断开或上游未返回 usage 时可能仍收费；本机统计不代表完整官方账单。

长历史自动化比较为本地固定样例：220 条近期候选只发送最多 6 条，组装结果低于 12000 字节估算预算，同时召回旧承诺。具体值见 `context-comparison.json`（若随交付提供）。这些不是实测模型 Token 节省比例。

本轮带真实密钥的生成请求为 0 次；真实 Token、响应耗时、连续故事总成本均未测量。AI 整理、世界建议分别展示范围和请求次数，需要单独确认；截断或过滤结果不写为正式建议。
