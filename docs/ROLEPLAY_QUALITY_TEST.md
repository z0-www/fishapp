# 人物演绎与质量验收

保留同一 CharacterProfile 与 Fish Roleplay Core，没有第二套人物系统或后台 NPC 调度。

本轮增强：人物提示包含自身语言习惯、喜恶、愿望、情绪、关系、价值与目标；新增情感线索及潜台词提示，尊重本人意愿与玩家行动。允许停顿、合理拒绝、怀疑、冷漠和复杂感情，不统一温柔，不为了独立而无故敌视。

RoleplayQualityChecker 对明确客服套话、重复台词给出非阻断本地提示，不伪造替代文本，不自动收费重试。世界状态仍由本地验证器决定，禁止替玩家决定关键行动、越权说话、瞬移与身份篡改。

## 已执行

- 不同 NPC 的人格卡和语言风格不同。
- 情绪、亲近请求与保密要求产生不同立场提示。
- 模拟响应中的上游过滤、JSON 失败与玩家代理权冲突分别追踪，不混称“违规”。
- 每个失败预算只执行一次，状态未提交。
- 原有三种世界 25 轮脚本、长期承诺、秘密、世界隔离与重开存档回归。
- 110 轮旧故事选定节点恢复与原文保护。
