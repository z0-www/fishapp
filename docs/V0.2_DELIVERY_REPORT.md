## 实现结果与体验方法

进入首页任意世界 → “进入文游 · V0.2” → 首次选择现代/民国/奇幻场景 → 输入自由行动 → 查看本轮预算并确认 → 获得当前 NPC 回复 → 自动保存。人物入口查看身份、位置和世界资料；可以保持选中对象连续交谈、前往相邻地点、停止生成或恢复未完成回合。

这是可以输入、回应、保存与继续的**本地规则试玩版**，不是已经完成真实模型验收的 AI 产品。默认界面明确标注“非真实 AI 输出”，不会读取密钥或发出 DeepSeek 请求。本轮还实现了受许可/debug/移动端开关限制的 DeepSeek 结构化 SSE 游戏适配器，但没有取得适用许可或使用真实 Key 测试。正式发布构建继续关闭真实直连。

## 新增功能与架构

- FishRoleplayCore / TurnCoordinator 组合 CharacterEngine、CharacterDecisionEngine、DialogueEngine、MemoryEngine、WorldContextBuilder、WorldStateValidator、Repository 与 Evaluator，按 domain/data/application/presentation 分离。
- 九名角色，三组主题的职业背景、目标、活动、价值观、语言风格与示例台词；档案包含用户要求的个人字段，不每轮全量发送。详细字段与取舍见 NPC_PERSONA_DESIGN.md。
- 每世界/每 NPC 独立记忆；短期原始回合、稳定档案/世界事实、个人经历分开；关键词/重要性/近期性/重复惩罚，来源标签不被悄悄抹掉。
- 自由输入、玩家意志边界、在场/存活检查、每轮单个发言者、相邻地点与有限时间提案；身份、生死、未取得物品变更不开放，不让模型凭空写入。
- 状态与正式消息、本人经历同事务提交；ledger 唯一 ID 和 revision 防重复/过期覆盖。同世界不并发 running；失败/停止不提交未验证状态；中断需手动恢复，不自动再次收费。
- 旧首页、创建、BYOK、费用、迁移模块均保留。schema 3→4 只增表，旧数据保留测试通过。新增聊天页是旧世界上的附加场景存档，不覆盖原世界 summary。

## 请求协议与成本

准备上下文 → 输入保守估算 → 用户确认 → running 占位 → 最多一次生成请求 → 缓冲完整 JSON → 单独解析 narration/replies/proposal → 校验整轮 → 正式展示并事务保存。非法提案/格式/发言者会拒绝整轮，不显示已经被否定的叙述。首版没有边生成边提交正文，选择正确性优先。

使用原 ApiKeyStorage 和 DeepSeekConfig 门槛，新 client 方法接收结构化 messages、JSON output、SSE、CancelToken、超时和 usage。授权头逐次传递，不进全局 headers，不加日志拦截器，不关证书验证。失败错误脱敏；不存 Key 到游戏表。

当前核验模型 deepseek-flash；输出最多1200 Token，输入 UTF-8 字节保守估算上限12000，每人近期最多三轮、相关记忆最多六条。不是精确 tokenizer，也不是每轮全量历史。

官方价格核验快照 2026-11-17：Flash 峰值每百万输入 miss USD 0.30、hit USD 0.006、输出 USD 1.20；非峰值减半。UI 用峰值和最大输出作参考预算，不把它当精确账单。服务返回的真实 input/output/cache Token 才写 usage，价格版本标记 peak-ceiling，estimatedUsd 仍为估算。当前时段、节假日、缓存和未来价格变化可能造成差异，实际账单以平台为准。开发者若更改模型须同步更新价格适配，不能沿用 Flash 价格。未知/缺失 usage 不编造 Token，断流或取消仍可能已收费，重试必须重新确认。Mock 不写任何实际账单或伪造 usage。

## 已知缺陷与下一版建议

1. 默认本地规则适配器可试玩，但台词有限、存在重复，不具有真实语言模型的自由推理能力；真实 DeepSeek 与自然度评分等待适用许可及真实输出。
2. 角色目标、活动、信任与情绪是轻量档案/规则，不是完整日程模拟、学习人格或自主常驻 Agent。没有全量世界书编辑器、自动反思或复杂撒谎策略；不把缺少这些能力包装为已完成。
3. 世界验证白名单保守，拒绝身份/死亡/物品变化。自然语言中的所有隐含矛盾不能由规则完全证明；控制玩家句式与秘密原文检查只是有限护栏。跨人物显式传闻传播/事实核验尚未开放，某些合法提案也会被保守拒绝。
4. 重要事件/剧情线程字段仅预留，正式演进事实以完成回合与状态为准。大规模长期记忆需进一步做 owner 索引分页、语义提取与可审计事实升级。
5. 仅保留最近100个正式回合作页面列表，数据库不删除更早记录；无完整历史分页和手动存档槽 UI。
6. 取消/断网前服务可能已计费，usage 未到达时无法获知精确消耗；当前只有状态校验前拿到的完整 usage 会记录。没有静默重试或虚假退款承诺。
7. 原 ZIP/JSON 完整导入、AI 整理里程碑仍未实现，沿用原暂存/预览边界；本轮没有重写这些模块。

下一版优先：取得许可后小规模真实同模型对照评测 → 真机停止/后台/崩溃验收 → 细分严重错误与更多状态提案 → 可追溯传闻/关系变化 → 长期记忆分页与历史查看。避免先做战斗、云账号、多供应商或常驻多 Agent。
