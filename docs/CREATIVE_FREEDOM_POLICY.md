# 创作自由度策略

FishCreativeFreedomPolicy 在本地进行有限情境筛查，不宣称“完全无审查”，不替代适用条款、上游安全或正式年龄分级。

## 三层处理

1. 正常文学：情感、反派、争吵、悲剧、战争、犯罪题材和恐怖氛围等，不因题材词整体拒答。允许冷漠、复杂立场、沉默与暂不和解。
2. 表现尺度：成熟题材、成年人非露骨关系采用边界内的表达，保留允许剧情。世界高级设置可选轻松日常 / 写实剧情 / 成熟题材，以及情感、冲突、恐怖、详细度 0–4；未操作时保持未设定。这些不是关闭限制的开关。
3. 明确受限：未成年人性化、露骨性内容、可执行现实伤害或违法指引、针对现实对象的威胁等。简短解释可继续的非露骨、非操作部分，不通过重写隐藏指令或重试绕过上游。

本地实现是小型词组、否定约束及请求意图的确定性规则，存在误判与漏判可能，不等于完整语义审核。无额外 Token 消耗。服务端仍独立处理安全限制。[DeepSeek 条款](https://cdn.deepseek.com/policies/en-US/deepseek-terms-of-use.html)对露骨性内容等有限制，“成熟题材”不能被宣传成无边界的色情聊天。

## 失败来源

ContentDecisionTrace 分开记录本地创作边界、上游明确拒答/过滤、JSON、世界状态校验、网络、Token/额度、角色质量、存储及配置。保留最近 100 项固定代码和时间，不额外存聊天原文、请求头或密钥。JSON 失败不标作内容违规。质量提示不自动中断已校验剧情或发起额外付费修复。

设置中的本地诊断可查看类型。反馈入口由用户预览后打开邮件到 `z0www1234@163.com`，不自动附带原文，未自动发送；不把本机诊断等同于开发者已收到举报。

## 实际测试

`test/fixtures/creative_cases.json` 共 114 个独立固定样例，其中正常/调整 82、明确限制 32。覆盖中文/英文情感、冲突、反派、悲剧、恐怖、犯罪文学、否定约束、无害医学/保护性讨论和高风险边界。

该样例集实际误拒 0，漏检 0；仅代表这组有限样例，不外推通用准确率。实际模型角色出戏率、剧情中断率、A/B/C 效果均未测量。测试报告 JSON 保留 null，不用 Mock 填充真实表现。
