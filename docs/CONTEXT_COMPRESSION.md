# 分层上下文与增量记忆

当前提供可运行的本地分层装配与原文索引基础，不把它称为已完成的语义摘要压缩。

| 层 | 当前内容 |
| --- | --- |
| L0 | 稳定的世界硬规则、玩家身份及已知背景 |
| L1 | 当前地点时间、发言角色档案和状态 |
| L2 | 当前 NPC 的相关个人记忆 |
| L3 | 已审核且在知情范围内的结构化事实、个人长期索引 |
| L4 | 最多三轮当前角色近期原文 |
| L5 | 玩家当前输入 |

ContextBudgetManager 使用 UTF-8 长度做保守估算，当前输入上限12000、输出上限1200；它不是模型精确 tokenizer。超限停止，不静默截断身份或世界硬规则。完整历史永久留在本机，不每轮发送全部历史。

PromptAssembler 将固定信息放在变动内容之前；ContextCachePlanner 可以计算前缀指纹。是否实际命中缓存取决于服务商，未宣称一定命中。

MemoryRetriever / 原 MemoryEngine 按 owner 隔离并检索相关内容。KnowledgeBoundary 只允许公开已审核事实，或用户指定知情人的项目。其他 NPC 私人秘密不进入当前人物上下文；导入原文也不自动全部公开。

## 手动整理

聊天“更多 → 记忆管理”可选择人物，预览新增条目和整理前后的估算，再确认写入新索引版本。IncrementalSummarizer 仅追加未索引的个人记忆，保留原文、出处、重要度及回合，不再全量调用模型。

ContextIntegrityValidator 检查全部该人物记忆 ID、owner 和原文一致性；丢失或改写任何条目会拒绝，保留旧版。原始世界规则、关系、事件、承诺、时间地点仍以结构化状态与来源记录为准，不由模糊一句摘要替换。

这是一种本地可审计的增量原文索引，可能比原记录更大，界面不承诺 Token 节省。真正的语义压缩、多级合并、动态预算调优、摘要调用成本分类与质量回归属于后续里程碑。

## 费用与比较

真实 usage 才进入 UsageRepository；输入、输出、缓存命中及推导的未命中数量分别显示。未返回或未估价保持未知，Mock 不写真实账单。本机月度预算为提醒，不是服务商硬额度，也无法涵盖其他设备及未返回用量。

当前只完成 Baseline 全历史与 Enhanced 分层方案的合成数据估算测试，以及事实/秘密边界检查。没有真实 DeepSeek 请求，因此没有实际输入输出 Token、缓存命中、费用或人格质量的对照结论。
