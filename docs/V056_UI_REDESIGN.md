# 鱼者文游 V0.5.6+31 页面与交互

| 页面 | 状态 | 功能前后对比 |
| --- | --- | --- |
| 文游聊天 | 已实现，已测试 | 重复的时间线、记忆和历史节点入口合并到「剧情与记忆」。六个主入口分别通往世界与人物、剧情与记忆、叙事偏好、故事备份、消费与用量、AI 服务设置。 |
| 叙事快调 | 已实现，已测试 | 一次点开工具图标，一次点预设、人称或风格即可从下轮生效。全局和世界编辑提供数字输入与滑块。 |
| 小说阅读 | 已实现，已测试 | 保留小说段落布局。旧段落阅读位置不会因新回合提交自动跳走，向上阅读时可点「跳到最新剧情」。 |
| 世界预览 | 已实现，已测试 | 有本地故事显示真实摘要和最近节点，时间可靠时显示最后游玩。空世界引导开始故事。 |
| 消费悬浮球 | 已实现，已测试 | 复用 `assets/branding/fish_logo.png` 与现有吸边。去掉正文侧边固定留白，滚动时淡化并放行阅读手势。保留显示开关、键盘避让和预算提示。 |
| 设置 | 已实现，已测试 | AI 与模型、故事与数据、费用与消费、关于鱼者分组。移除无操作的列表项，保留产品声明。 |
| 意见反馈 | 已实现，已测试 | 复核已实现的邮箱展示与复制。点邮箱不会打开邮件，复制后显示「邮箱已复制」。本页只用于普通反馈。 |
| 历史阅读 | 已实现，已测试 | 从逐条卡片改为连续段落。懒构建可见消息，首尾跳转保持原始顺序，来源与完整性在展开区独立显示。 |
