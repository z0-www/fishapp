鱼者文游隐私政策

发布前审核稿 · 2026 年 11 月 19 日

鱼者文游由 B 站 UP 主 z0-www 独立开发。隐私联系邮箱为 z0www1234@163.com。

设备上的故事和密钥

世界设定、角色、聊天、草稿、导入原文、附件和用量记录保存在设备上，用于阅读、继续故事、恢复与费用控制。鱼者文游没有自己的账号系统、云端故事存储或请求代理。API Key 由系统安全存储保护，与故事数据库分离。Android 使用系统 Keystore 保护的加密存储。iOS 使用仅本机的 Keychain。

DeepSeek 在线服务

在在线功能已启用的构建中，发起剧情生成、连接测试或 AI 整理时，鱼者文游通过 HTTPS 将 API Key 和完成此次请求所需的输入或世界上下文直接发送给 DeepSeek。阅读离线剧情不会触发模型调用。打开消费管家或刷新余额时，余额查询向 DeepSeek 发送 API Key，无需上传剧情。模型调用按逐次确认或你主动设置的有效消费授权执行。模型计费及 DeepSeek 接收后对数据的处理由 DeepSeek 自己的政策说明。请避免在故事或请求中输入不必要的个人信息。

DeepSeek 隐私政策

导入、导出与分享

你可以主动分享、选择文件或粘贴正文。获准的公开分享读取会匿名连接 DeepSeek 官方地址，不使用账号 Cookie 或 API Key。持有公开分享链接的人可能看到相应内容。导出的完整故事备份可设置密码，不包含系统存储中的 API Key。请谨慎分享备份和原始故事。

留存、删除和联系

设备上的故事由你管理。可从 AI 服务设置删除密钥，从世界设置删除选定世界。与世界关联的导入原文可以独立保留。清除应用数据会移除设备内的故事与档案，已复制或导出到其他位置的文件请自行处理。更换设备或安装不同签名的版本前，请先把完整备份保存到应用以外的位置。涉及 DeepSeek 侧的数据，请按其政策提供的方式管理。你可通过上方邮箱就鱼者文游隐私处理提出问题。
